## Built `kiosk/index.html` + `kiosk/data.js`
Single-file kiosk page (Bahasa Indonesia, 1440×900, no scrolling) for the
Graph-SIR rumour-spread project. GitHub Pages target.

- `kiosk/index.html` — all CSS/JS inline, Canvas 2D only, no CDN/fonts/images,
  no `fetch` (works from `file://`). Only external file is `data.js`.
- `kiosk/data.js` (892 KB) — generated. `n`, flat `edges`, flat `xy` (0..1000,

## Key finding: seed pools come from the research output, not recomputed centrality
`sim_output/sims_*.dat` are pickles of `SimulationResult` namedtuples whose
`first_spreader_idx` field records the seed of every run. The 30 distinct values
per file ARE the study's seed pools:

- `sims_bc` → `top_bc`, `sims_cc` → `top_cc`, `sims_deg_bc` → `deg_matched`
- Verified the files reproduce the published numbers exactly:
  BC escape 87.40% / mean 0.4546 / sd 0.2666, CC 99.00% / 0.5621 / 0.1592.

**Unpickling trick:** the pickles embed a `graph_tool.PropertyArray` (the
`rumor_size` series). graph-tool isn't installed locally, so stub it:

```python
gt = types.ModuleType('graph_tool')
class PropertyArray(np.ndarray): pass
gt.PropertyArray = PropertyArray
sys.modules['graph_tool'] = gt
```
…and define `SimulationResult` in `__main__` before `pickle.load`.

## Model parameter mapping (brief ↔ notebook)
`lambda=0.20` ↔ `ignorant_believe_probability`;
`gamma=0.05` ↔ `spreader_disagreement_probability`;
`eta=0.10` ↔ `spreader_disillusionment_probability`;
`delta=0.50` ↔ `spreader_forget_probability`;
`stifler_forget_probability = 0` → stifler is absorbing.
Max time step in practice is only ~22–27, so the 300-step cap is never hit.

## Verification technique (reusable)
To exercise a page's inline script without a browser: extract the
`<script>` body from the HTML with a regex, inject
`globalThis.__t = {...}` just before the closing `})();` to expose internals,
then `vm.runInThisContext` it against a stub `document`/`window`/`Path2D`
(Proxy-based canvas ctx). Catches parse errors, DOM-wiring errors, and lets you
assert on the real simulation maths. See `/tmp/kiosk_test2.js` pattern.

## Where `data.js` actually is
Not `web/data.js`, not `./data.js`, not `./sim_output/data.js` — it is
**`docs/data.js`** (910 KB, generated by `tools/kiosk/build_data.py`).
`web/scripts/convert-data.mjs` reads it and writes `web/public/graph.json`
(866 KB). It cannot `JSON.parse`: the file is JS with `//` comments and unquoted
keys, so it is evaluated in a `node:vm` context with a `window` shim.

## The engine reproduces the paper — and the one number that does not match
`web/src/sim/engine.ts` implements the brief's section 4 literally. Validated
two ways (`npm run validate`):

1. Strategies as the site seeds them → BC 0,4631 / 86,2%, CC 0,5576 / 97,2%.
2. **On the study's own pools** recovered from `sim_output/sims_*.dat` →
   BC 0,4631 vs paper 0,4546 · CC 0,5576 vs 0,5621 · Acak 0,2769 vs 0,2914.
   Within 1,5 pp of escape rate. The engine is correct.

**The Acak mismatch is a pool difference, not an engine difference.** The
paper's Acak pool is 30 fixed nodes with mean degree 52,9, and six of them are
near-duds (per-node escape 7%, 10%, 11%, 12%, 12%, 12%). The average of the 30
per-node rates is **65,0%** — matching the paper's 64,2% and the engine's 62,8%
on that same pool. Uniform sampling over all 4.039 nodes gives ~75%, which is
what the site does (the brief specifies it). Disclosed in a footnote on
`/hasil`. Twelve fresh 30-node pools spanned 60,4%–85,0%, so one 30-node pool is
a very noisy estimator — worth remembering before treating any single-pool
number as a property of the network.

## Sandbox gotchas worth reusing
- **`npm install` fails** in this sandbox:
  `CODEBUDDY_BROKER_DENY: Brokered host mkdir requires an available runtime file
  rule`. Worked around with
  `pnpm install --node-linker=hoisted --allow-build=esbuild` — the hoisted linker
  avoids npm's bin-linking rename, and without `--allow-build` esbuild's
  postinstall is skipped and Vite cannot build. `pnpm-lock.yaml` and
  `pnpm-workspace.yaml` were deleted before committing so the repo stays
  npm-based.
- **pnpm is a corepack shim** and prompts interactively on first use. Set
  `COREPACK_ENABLE_DOWNLOAD_PROMPT=0`.
- **Node 22.22 strips TypeScript types natively**, so `scripts/validate.mjs`
  imports `src/sim/engine.ts` directly — no build step. The engine is kept
  self-contained and erasable-syntax-only for exactly this reason.
- **`vite preview` binds IPv6 only** (`[::1]`), so `curl 127.0.0.1:PORT` fails
  with 000. Use `localhost` or `[::1]`.
- No PDF tooling exists here (`pdftotext` absent, no `pypdf`/`pymupdf`), and a
  stdlib zlib stream extractor returned binary noise. The team's
  `Research_Paper.pdf` could not be read, so the research question wording on
  `/tentang` is reconstructed from the title — the team should check it.
