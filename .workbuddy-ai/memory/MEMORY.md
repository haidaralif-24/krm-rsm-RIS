# rumour-spread-model — project notes

Graph-SIR rumour-spread study on SNAP ego-Facebook (4,039 nodes / 88,234 edges).
Seeding at high-Betweenness vs high-Closeness nodes. **Result contradicts the
original hypothesis: Closeness wins** — 99.0% escape vs 87.4%, mean final size
0.562 vs 0.455, SD 0.159 vs 0.266.

## Layout
- `datasets/facebook_combined.txt` — SNAP ego-Facebook, 88,234 undirected edges.
- `sim_output/` — plots plus `sims_*.dat` pickles of every simulation run.
- `sir_graph_simulation_*.ipynb` — graph-tool notebooks (original + modified).
- `project_writeup.pdf` — Reyes's 2018 writeup (the upstream model, MIT).
- `Research_Paper.pdf` — **the team's own paper** (8 pages). Untracked in the
  main repo; a copy is served as `web/public/paper.pdf`.
- `docs/` — the science-fair kiosk page, published via GitHub Pages
  (Settings → Pages → Branch: `master`, Folder: `/docs`). Contains only
  `index.html` + `data.js`.
- `tools/kiosk/` — dev-only scripts: `build_data.py` regenerates `docs/data.js`,
  `validate_model.py` re-checks the model against the published numbers.
  Deliberately outside `docs/` so they are not served on the web.
- **`web/` — the Vercel app, in its own git repository, NOT part of this repo.**
  Remote `haidaralif-24/rsm-website`, branch `main`, deployed to Vercel from
  there with the app at that repo's **root** (so Vercel's Root Directory must be
  left blank — never `web`). This repo ignores it: `/web` is in the root
  `.gitignore` (commit `e3d6ea4` on `master`), the files were untracked with
  `git rm -r --cached web`, and the local `web-app` branch that had held them was
  deleted. `git ls-tree -r HEAD` and the whole reachable history contain **0**
  files under `web/`. Decisions log: `web/NOTES.md`; deploy notes:
  `web/DEPLOY.md`.

## Conventions
- Working language is **Indonesian**; code comments in English.
- Indonesian number formatting: **comma as decimal separator** (`99,0%`, `0,562`).
  Thousands use a period (`4.039 node`).
- The research model's stifler state is **absorbing**; nothing returns to Ignorant.

## Gotchas
- The notebooks need **graph-tool** (normally via Docker). Local Python can't run
  them, but `sim_output/sims_*.dat` can be unpickled by stubbing
  `graph_tool.PropertyArray` as an `np.ndarray` subclass.
- Those pickles are the authoritative record of the seed pools actually used.
  Prefer them over re-deriving top-30 centrality lists.
- Palette is orange / teal / navy only — no green, red or blue for states.
